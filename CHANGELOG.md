# Veyra changelog

No public release has been made. The repository's package versions describe development candidates, not publication status.

Pending user-visible changes live in [`.changeset/`](.changeset/). During local release preparation, Changesets generates `CHANGELOG.md` in each affected package and updates the fourteen official packages together. Package changelogs are included in their tarballs when present.

Use `pnpm release:status` to preview the next version and [Versioning](docs/VERSIONING.md) for bump policy, compatibility and local preparation commands. Publication is a separate human-approval boundary; there is no automatic release on a normal development commit.
