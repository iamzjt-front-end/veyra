# @veyra/dashboard

Status: **planned for v0.5**.

The Dashboard will be Veyra's Web-based Agent Control Center for multi-project management, workflow visualization, run history, approvals, metrics, and remote workers.

It must consume the same core event/state model as the CLI and TUI rather than implementing orchestration logic itself.

Implementation awaits the stable-TUI prerequisite recorded in [M5.1](../../docs/TODO.md). The independent [remote-control design](../../docs/REMOTE-CONTROL-DESIGN.md) is available for future review; no server, remote worker or remote command endpoint is implemented.
