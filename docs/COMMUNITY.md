# Community channels

Use [GitHub issues](https://github.com/iamzjt-front-end/veyra/issues/new/choose) for reproducible bugs, scoped proposals and usage questions. Search existing issues and the [documentation](../README.md) first. The templates ask for enough evidence to reproduce behavior without collecting credentials or complete private histories.

GitHub Discussions remains **disabled**. At this stage, issues keep questions and design proposals discoverable in one maintained queue; the roadmap and TODO remain the execution plan. Revisit Discussions when recurring conversations justify a separate moderated space, with an explicit owner and categories before enabling it. This decision adds no chat service, mailing list or support SLA.

[Contributing](../CONTRIBUTING.md) explains implementation/review, [Code of Conduct](../CODE_OF_CONDUCT.md) covers participation and abuse reporting, and [Security](../SECURITY.md) provides the enabled private vulnerability channel. Never use a public issue for credentials, exploit details or private conduct reports.
